# DMD — сайт и локальная админка

Шесть направлений: AI-автоматизация, сайты, CRM, AI-видео, тестирование и SaaS. Форма отправляет обращения в SQLite, а отдельная админка показывает контакт, компанию, бюджет, услуги и полный текст задачи.

## Запуск на Mac

1. Открой `Запустить DMD.command` двойным щелчком. Оставь окно терминала открытым.
2. Сайт: <http://127.0.0.1:8787>.
3. Админка: <http://127.0.0.1:8787/admin>.
4. При первом посещении админки создай логин и пароль (не менее 12 символов). Сохрани их в менеджере паролей. Дальше доступна только форма входа.
5. Для остановки нажми `Ctrl+C` в терминале.

Требуется Node.js 24 LTS или новее с `node:sqlite`. Скрипт использует установленный Node.js либо совместимый runtime Codex на этом Mac. Установка дополнительных npm-пакетов не нужна. Из терминала можно запустить `node server.mjs`.

Сервер слушает только `127.0.0.1`: эта версия предназначена для локальной проверки на одном компьютере. Открытие `dist/index.html` как файла позволяет посмотреть дизайн, но для отправки нужен адрес сервера выше. GitHub Pages не запускает этот сервер.

## Заявки и вход

- Имя, контакт (телефон, email или Telegram `@username`) и описание задачи обязательны. Выбор конкретной услуги необязателен.
- Отправка считается успешной после сохранения в SQLite. Повтор запроса после сбоя связи с тем же идентификатором не создаёт дубликат.
- В админке доступны поиск, фильтры, страницы по 30 заявок и статусы: новая, в работе, завершена, архив.
- Статус сохраняется в базе. Если другой сеанс уже обновил заявку, сервер сообщит о конфликте.
- Пароль хранится как хеш с солью (scrypt), сессия — в HttpOnly cookie и живёт 8 часов. Выход аннулирует сессию. Доступа к заявкам без входа нет.
- Общий аккаунт создаётся один раз. Управление несколькими сотрудниками и восстановление пароля по почте в эту локальную версию не входят.

## Данные

База находится в `data/dmd.sqlite`; рядом могут появляться служебные файлы SQLite `-wal` и `-shm`. Папка `data/`, `.env` и локальные логи исключены из Git. Не добавляй их в репозиторий: база содержит клиентские обращения и хеш доступа.

Для резервной копии останови сервер и скопируй всю папку `data/` в защищённое место. Для восстановления останови сервер и верни сохранённую папку. Не удаляй базу для смены пароля — вместе с ней будут потеряны обращения.

В тестах используется отдельная временная база; реальные данные не затрагиваются. При необходимости другой базы для проверки: `DMD_DB_PATH=/absolute/path/test.sqlite PORT=8788 node server.mjs`.

## Проверка

```sh
node --test test/server.test.mjs
```

Проверяется сохранение после перезапуска, повторная отправка без дублей, валидация, недоступность данных без входа, статусы, поиск, сессии и блокировка запросов с другого сайта.

Для публичного запуска нужен отдельный этап: серверный хостинг с постоянным диском, HTTPS, настройка доступа и резервного копирования. Текущая версия в интернет не развёрнута.
